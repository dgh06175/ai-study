# SSE Practice Project - Frontend

Python tkinter를 사용한 간단한 GUI 채팅 클라이언트입니다.

## 기능

1. **대화방 생성**: 새로운 대화방을 만들 수 있습니다.
2. **대화방 선택**: 기존 대화방 목록에서 선택할 수 있습니다.
3. **실시간 채팅**: SSE를 통해 실시간으로 AI 응답을 받을 수 있습니다.
4. **대화방 관리**: 대화방 이름 변경 및 삭제가 가능합니다.

## 실행 방법

1. conda 환경 활성화:
   ```bash
   conda activate sse
   ```

2. 필요한 패키지 설치:
   ```bash
   cd frontend/
   pip install -r requirements.txt
   ```

3. 백엔드 서버가 실행 중인지 확인 (http://localhost:8000)

4. GUI 클라이언트 실행:
   ```bash
   python main.py
   ```

## 사용법

1. **새 대화방 생성**:
   - "새 대화방 이름" 입력란에 원하는 이름을 입력하고 "생성" 버튼 클릭
   - 이름을 비워두면 자동으로 생성됩니다

2. **대화방 선택**:
   - 드롭다운 메뉴에서 원하는 대화방을 선택

3. **메시지 전송**:
   - 하단의 메시지 입력란에 메시지를 입력하고 "전송" 버튼을 클릭하거나 Enter 키를 누릅니다
   - AI가 실시간으로 토큰 단위로 응답을 스트리밍합니다

4. **대화방 관리**:
   - "새로고침" 버튼으로 대화방 목록을 업데이트
   - "삭제" 버튼으로 현재 선택된 대화방을 삭제

## 기술 스택

- **GUI**: Python tkinter (표준 라이브러리)
- **HTTP 클라이언트**: requests
- **SSE**: Server-Sent Events 실시간 스트리밍
- **멀티스레딩**: GUI 응답성을 위한 백그라운드 처리

## 주요 특징

- 🎨 **간단한 GUI**: tkinter를 사용한 직관적인 인터페이스
- ⚡ **실시간 스트리밍**: SSE를 통한 토큰 별 실시간 응답
- 🧵 **비동기 처리**: GUI 블로킹 없이 백그라운드에서 네트워크 요청 처리
- 🏠 **대화방 관리**: 여러 대화방 생성 및 관리
- 🔄 **자동 새로고침**: 대화방 목록 자동 업데이트
