# SSE Practice Project - Web Frontend

Flask를 사용한 웹 기반 SSE 채팅 클라이언트입니다.

## 🌟 특징

- **웹 기반 인터페이스**: 브라우저에서 바로 사용 가능
- **실시간 SSE 스트리밍**: JavaScript Fetch API로 토큰별 실시간 응답
- **반응형 디자인**: 모바일과 데스크톱 모두 지원
- **Bootstrap UI**: 현대적이고 깔끔한 인터페이스
- **그라데이션 디자인**: 시각적으로 매력적인 채팅 인터페이스

## 📁 파일 구조

```
frontend/
├── web_app.py              # Flask 웹 서버
├── web_requirements.txt    # 웹 버전 의존성
├── templates/              # HTML 템플릿
│   ├── base.html          # 기본 레이아웃
│   ├── index.html         # 메인 페이지 (대화방 목록)
│   └── chat.html          # 채팅방 페이지
├── static/                # 정적 파일
│   └── style.css          # CSS 스타일
├── main.py                # Tkinter 버전 (기존)
└── README.md              # 사용법 가이드
```

## 🚀 실행 방법

1. **환경 준비**:
   ```bash
   conda activate sse
   cd frontend/
   pip install flask
   ```

2. **백엔드 서버 확인**: `http://localhost:8000` 실행 중인지 확인

3. **웹 서버 실행**:
   ```bash
   python web_app.py
   ```

4. **브라우저 접속**: `http://localhost:3000`

## 🎮 사용법

### 대화방 관리
1. **대화방 생성**: 메인 페이지에서 이름 입력 후 "대화방 생성" 클릭
2. **채팅 시작**: 대화방 목록에서 "채팅" 버튼 클릭
3. **대화방 삭제**: "삭제" 버튼으로 불필요한 대화방 제거

### 실시간 채팅
1. **메시지 입력**: 하단 입력창에 메시지 작성
2. **전송**: Enter 키 또는 "전송" 버튼 클릭
3. **실시간 응답**: AI가 토큰별로 실시간 스트리밍 응답

## 🎨 UI 특징

- **그라데이션 배경**: 보라색 계열의 아름다운 그라데이션
- **타이핑 애니메이션**: AI 응답 중 깜빡이는 커서 표시
- **상태 표시**: 연결 상태 및 스트리밍 진행 상황 표시
- **반응형**: 모바일 환경에서도 최적화된 UI

## 🔧 기술 스택

- **백엔드**: Flask (Python)
- **프론트엔드**: HTML5, CSS3, JavaScript
- **UI 프레임워크**: Bootstrap 5
- **아이콘**: Font Awesome
- **SSE 처리**: JavaScript Fetch API with streaming

## 🌐 웹 vs Tkinter 비교

| 특징 | 웹 버전 | Tkinter 버전 |
|------|---------|-------------|
| **접근성** | 브라우저에서 바로 사용 | 별도 실행 필요 |
| **UI/UX** | 현대적, 반응형 | 전통적인 데스크톱 |
| **설치** | 브라우저만 있으면 OK | Python 환경 설정 |
| **디자인** | 그라데이션, 애니메이션 | 단순한 위젯 |
| **확장성** | 웹 기술 활용 가능 | 제한적 |

## 📱 화면 구성

### 메인 페이지 (`/`)
- 대화방 생성 폼
- 대화방 목록 테이블
- 사용법 안내

### 채팅방 페이지 (`/rooms/<room_id>`)
- 실시간 채팅 인터페이스
- 메시지 입력창
- 연결 상태 표시

## 🎯 주요 기능

1. **실시간 스트리밍**: 초당 30토큰 속도로 자연스러운 응답
2. **연결 상태 모니터링**: 백엔드 서버 연결 상태 실시간 확인
3. **오류 처리**: 네트워크 오류 시 사용자 친화적 메시지 표시
4. **스크롤 자동 이동**: 새 메시지 도착 시 자동으로 스크롤
5. **타이핑 방지**: 스트리밍 중 중복 요청 방지
